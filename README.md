# Sistema de Gestión de Complejo Deportivo

Trabajo Obligatorio - Programación de Aplicaciones Java Enterprise Web (UDE).

## Tecnologías utilizadas
* **Backend:** Jakarta EE / EJB (`@Stateless`)
* **Persistencia:** JPA / Hibernate
* **Base de Datos:** MySQL
* **Servidor de Aplicaciones:** WildFly

## Estructura del Proyecto
* `Obligatorio-ejb`: Entidades JPA (`Cliente`, `Cancha`, `Reserva`) y Session Beans con la lógica de negocio.
* `Obligatorio-war`: Controladores y vistas web.
